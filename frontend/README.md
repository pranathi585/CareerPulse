# CareerPulse

CareerPulse is a career intelligence dashboard that helps users understand their skills, career opportunities, skill gaps, and potential career paths.

## Features

- Career readiness assessment
- Skill profile visualization
- Career role matching
- Skill gap analysis
- Career action recommendations
- Career scenario simulator
- Occupational skill analysis using O*NET data
- Python-based data processing
- SQL-based career analysis

## Technology Stack

- React
- JavaScript
- Python
- Pandas
- SQLite
- SQL
- O*NET occupational data

## Data Pipeline

O*NET occupational data is processed using Python and Pandas.

The processed data is stored as CSV and SQLite data and used to support the CareerPulse analysis.

```text
O*NET Data
    ↓
Python + Pandas
    ↓
Processed Career Data
    ↓
SQLite + SQL Analysis
    ↓
React CareerPulse Dashboard
